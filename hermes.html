⬡ Arquitecturas de Agentes más usadas

A. ReAct Loop — La más común. El modelo razona, actúa, observa y repite.

User ──> Hermes (piensa + actúa) ──> tool ──> observa ──> piensa ──> tool ──> ... ──> respuesta final // Internamente genera: Thought → Action → Observation → Thought → Final Answer

B. Plan-and-Execute

Planner ──> lista de pasos (JSON) │ ├──> ejecuta paso 1 (tool) ├──> ejecuta paso 2 (tool) └──> ejecuta paso 3 (tool) │ └──> verifica → reporta

C. Multi-Agent Orquestado

Orchestrator (Hermes) │ ├── Planner ── define plan en steps ├── Worker A ── backend ├── Worker B ── frontend └── Reviewer ── revisa diff → pasa / falla │ └── reporte final

Frameworks: CrewAI, AutoGen, pi-subagents. Cada agente tiene system prompt y tools acotados.

D. Tool-Augmented LLM (TALL) — La variante más simple.

User ──> Hermes (system + tool definitions) ──> decide tool ──> ejecuta ──> devuelve resultado

Hermes 2 Pro y Hermes 3 tienen fine-tuning específico para JSON mode con tool calls nativas.

✦ Dato clave

Hermes 3 (Nous Research) está fine-tuneado sobre Llama 3.1 y tiene una de las mejores tasas de acierto en function calling del ecosistema open-source. Por eso es el backbone elegido en tantos agentes autónomos: no solo entiende la instrucción, sino que sabe cuándo y cómo llamar herramientas.

Modelos principales: Hermes 2 Pro (Mistral-based), Hermes 3 (Llama 3.1-based), Hermes 3 70B, Hermes 3 405B.
